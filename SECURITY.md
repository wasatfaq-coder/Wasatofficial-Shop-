# Политика безопасности

## Как сообщить об уязвимости

Не публикуйте уязвимости в открытых Issues. Используйте
[приватный отчёт GitHub](https://github.com/wasatfaq-coder/Wasatofficial-Shop-/security/advisories/new)
(вкладка **Security → Report a vulnerability**). Мы ответим в течение 7 дней.

## Модель безопасности

Приложение обращается к Cloud Firestore напрямую из браузера. Данные защищают правила
`firestore.rules` и Cloud Function `placeOrder`, которая оформляет заказы на сервере.
Любые проверки в клиентском коде (включая пароль панели администратора) можно обойти.

| Коллекция | Чтение | Запись |
|---|---|---|
| `products` | все | администратор; покупатели — отзывы, а до включения серверных заказов ещё и остатки |
| `promos` | все | администратор; покупатели — счётчики использования, только до включения серверных заказов |
| `banners`, `settings`, `delivery_methods`, `pickup_points` | все | администратор |
| `orders` | владелец (`customerUid`) и администратор | до включения серверных заказов — любой (с базовой проверкой), после — только Cloud Function; изменять — администратор |
| `chat_messages` | свой диалог (`threadId` = uid) без внутренних заметок; администратор — всё | покупатель — сообщения в свой диалог; изменять и удалять — администратор |
| `users` | владелец и администратор | владелец (кроме `bonusPoints`, `managerNotes`, `tags`) и администратор |
| `customer_notes` | администратор | администратор |
| `admins` | своя запись | только через Firebase Console |

Серверные заказы включаются флагом `settings/server.serverOrdersEnabled` (см. README → «Серверная часть»).
Функция `placeOrder` работает через Admin SDK и сама проверяет данные: пересчитывает цены,
доставку и промокоды, проверяет остатки.

Администратор — верифицированный Google-аккаунт владельца или пользователь с документом
`admins/{uid}`. Правила проверяются тестами в `tests/firestore.rules.test.mjs`
(они запускаются в CI).

## Известные ограничения

- **Пока флаг `serverOrdersEnabled` выключен**, сумма заказа, списание остатков и учёт
  промокодов считаются в браузере. Включите серверные заказы (нужен тариф Blaze).
- **Онлайн-оплаты нет.** Статус «оплачен» ставится без реального платежа, как и раньше.
  Для онлайн-оплаты нужна интеграция с платёжным провайдером и подтверждение платежа на сервере.
- **Нет защиты от спама заказами и сообщениями.** Функция и правила не ограничивают частоту
  запросов. При необходимости подключите Firebase App Check.
- **Пароль панели администратора** хранится в `localStorage` и служит только вторым
  шагом в интерфейсе. Смените пароль по умолчанию.
- **Журнал движения остатков** в панели администратора ведётся локально в браузере, поэтому
  списания, сделанные сервером, в нём не отображаются.
