# Политика безопасности

## Как сообщить об уязвимости

Не публикуйте уязвимости в открытых Issues. Используйте
[приватный отчёт GitHub](https://github.com/wasatfaq-coder/Wasatofficial-Shop-/security/advisories/new)
(вкладка **Security → Report a vulnerability**). Мы ответим в течение 7 дней.

## Модель безопасности

Приложение работает целиком в браузере и обращается к Cloud Firestore напрямую.
Поэтому единственная серверная защита данных — правила `firestore.rules`.
Любые проверки в клиентском коде (включая пароль панели администратора) можно обойти.

| Коллекция | Чтение | Запись |
|---|---|---|
| `products` | все | администратор; покупатели — только остатки (`skus`, `inStock`) и отзывы |
| `promos` | все | администратор; покупатели — только счётчики использования |
| `banners`, `settings`, `delivery_methods`, `pickup_points` | все | администратор |
| `orders` | владелец (`customerUid`) и администратор | создать может любой (с базовой проверкой); изменять — администратор |
| `chat_messages` | все (см. ограничения) | покупатель создаёт свои сообщения; изменять и удалять — администратор |
| `users` | владелец и администратор | владелец и администратор |
| `admins` | своя запись | только через Firebase Console |

Администратор — верифицированный Google-аккаунт владельца или пользователь с документом
`admins/{uid}`. Правила проверяются тестами в `tests/firestore.rules.test.mjs`
(они запускаются в CI).

## Известные ограничения

Для их устранения нужна серверная логика (например, Cloud Functions):

- **Цена и оплата заказа не проверяются на сервере.** Сумма заказа, списание остатков
  и учёт промокодов считаются в браузере. Перед отгрузкой проверяйте заказы вручную.
  Для онлайн-оплаты нужна интеграция с платёжным провайдером и проверка на сервере.
- **Чат поддержки общий.** Все покупатели видят одну ленту сообщений, включая внутренние
  заметки сотрудников. Не пишите в чат персональные данные. Решение — отдельные диалоги
  на каждого пользователя.
- **Профиль пользователя** (включая `bonusPoints`) может изменять сам пользователь.
- **Пароль панели администратора** хранится в `localStorage` и служит только вторым
  шагом в интерфейсе. Смените пароль по умолчанию.
