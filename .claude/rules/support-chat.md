# Чат поддержки

## Чат поддержки
- Сообщения с `threadId` (uid покупателя; у гостя — анонимный uid из отдельного Firebase-приложения `guest-chat`).
  Чат из карточки заказа открывается с «Вопрос по заказу № …» в поле (`openSupportChat(orderId)` → `draftText`).
  У каждого сообщения есть поле `isInternalNote`: правила отдают покупателю только сообщения с
  `isInternalNote == false` и отклоняют запрос без этого фильтра, так что сообщение без поля он не увидит.
- Бота и автоответов нет: покупатель пишет только `sender: 'user'` (правила), отвечают сотрудники; приветствия нет —
  пустой диалог показывает «Диалог пуст», статус отправки — настоящий (`pendingChatIds`/`failedChatMessages`).
  Свой диалог покупатель читает из базы с первого открытия чата за визит (`chatOpen` в `useSupportChat`, аудит 07.10,
  находка 50; до первого снимка пустой диалог — «Загружаем переписку…», а не «Диалог пуст»), кэш — в браузере
  (`manstyle_chat_messages_v2`), показывается до снимка базы; стирается,
  только когда вход чата определился и диалога нет (`chatIdentityKnown` в `useSupportChat`), и при выходе. Окно чата
  прокручивается в конец при открытии и новом сообщении, а не при каждой отрисовке (аудит 07.10, находки 25, 26).
- У сообщения серверное `sentAt` (правила: `== request.time`); фото покупателя — только `data:image/…` (не внешняя
  ссылка), сжатое: фото, которое браузер не сжал (HEIC), чат не отправляет (`isStorablePhoto` в `compressChatImageFile`).
  Ошибка правки сообщения — «15 минут» только при отказе правил (`permission-denied`). Фото сообщения — отдельный документ `chat_images/{id сообщения}` (этап 6, находка 20), в сообщении — `imageId`;
  пишется одним пакетом с сообщением (`saveChatMessageToFirestore`), удаляется вместе с ним (покупатель — как сообщение:
  своё и 15 минут), читает тот, чей диалог, и администратор (`ChatPhoto` подгружает при показе). Фото до 420 000 знаков,
  фото чека — до 900 000. Покупатель не пишет фото внутрь сообщения (`imageUrl`); старые такие сообщения показываются как раньше. Покупатель правит/удаляет свое сообщение 15 минут (`canCustomerChangeMessage`, в правилах — по `sentAt`),
  сотрудники — любое без срока. «Удалить у себя» — `hiddenForCustomer`/`hiddenForStaff`, «у всех» — удаление
  документа (`applyChatMessageChange`).
- Фото чека к заказу — сообщение покупателя с `receiptOrderId` (правила пускают это поле, до 40 знаков); на нём
  администратор подтверждает оплату или отклоняет чек («Доработки 5»).
- Админка: один список диалогов `AdminSupportInbox` → `AdminSupportChatTab`; статус и приоритет диалога —
  `support_threads/{threadId}` (только администратор), в шапке диалога — под одной кнопкой «Диалог» вместе с «Очистить
  переписку»; шаблоны ответов — один список в базе `settings/chat_templates` (только администратор, `useChatTemplates`;
  старые из браузера переносятся при первом открытии чата); статус для покупателя дублируется в
  `support_status/{threadId}` (читает сам покупатель, всплывающее уведомление при открытии чата). «Промокод» в чате:
  выбрать действующий из «Промокодов» (новый не создается) или создать новый.
