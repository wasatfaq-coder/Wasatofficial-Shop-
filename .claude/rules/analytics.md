# Аналитика

- `AdminAnalyticsTab` считается по заказам после `settings/analytics.resetAt`; «Сбросить статистику» заказы не
  удаляет, «Вернуть всю историю» снимает сброс. Числа экрана и PDF — `computeFirestoreDailySales`
  и `computePeriodBreakdown` (`src/utils/analyticsEngine.ts`), по цене и названию из заказа. Фото «Топа товаров» —
  только из каталога по id (`OrderLineThumbImage`, проп `products`), не из заказа: строку пишет посетитель, и ссылка
  выдала бы IP владельца (аудит 07.10, находка 7).
- Показатель графика выбирают карточки KPI (`role="radio"`: `neu-flat neu-pressable` → выбранная `neu-pill-active`),
  отдельного переключателя нет; «Пик» — чип в шапке графика. Тени модуля — только `neu-*`; SVG-тень столбцов
  (`neu-bar-elevation`) повторяет `--neu-raised-sm`.
- Период выбирается в модальном окне (`AdminAnalyticsPeriodDialog`); график не пересоздается при переключении (без `key`).
- Опт и розница (этап 19 `docs/admin-wholesale-plan.md`, решение владельца 09.10): заказ оптовый, если хоть одна его строка
  по оптовой цене (`priceKind` `wholesale` или `pack`), — `orderSalesChannel` в `src/shared/orderLine.ts`; заказ уходит
  в свой разрез целиком, исторические заказы — розница. Чипы «Все продажи / Розница / Опт» меняют все цифры страницы
  (опция `channel` у `computeFirestoreDailySales`), блок «Чистый доход: розница и опт» показывает обе стороны всегда.
- Чистый доход — только `src/utils/salesProfit.ts`: деньги за товары оплаченных заказов (`orderRevenue` без `deliveryFee`;
  промокод, правка заказа и оптовая цена строки уже в сумме) минус себестоимость строк. Себестоимость строки — снимок
  на момент продажи (`order_costs/{заказ}`, `src/utils/orderCosts.ts`), иначе сегодняшний `costPrice` товара с пометкой
  «≈ — оценка»; товар без себестоимости считается по 0 ₽ и называется отдельно («чистый доход завышен»). Себестоимость
  в заказ не пишется: строку заказа читает покупатель. Возврат из «Корректировки заказа» уже вычтен из `totalPrice`
  и второй раз не вычитается (`refundOutsideTotal` в `orderRevenue.ts`). Частичный возврат — только по выбранной модели
  (решение владельца 10.10): «Корректировка заказа» убирает модель или её количество из строк, и выручка, и себестоимость
  уменьшаются ровно на неё; «Вернуть и доставку» обнуляет `deliveryFee` заказа, поэтому доставка уходит из суммы один раз
  и из дохода второй раз не вычитается. У старого возврата без правки состава (`refundAmount` сверх журнала) строк нет —
  себестоимость остаётся вся.
- Периоды — только `src/utils/analyticsPeriods.ts`: готовые (7/14/30 дней, 6/12 месяцев) и «Свой период» (обе даты
  включительно, сравнение — с тем же числом дней перед ним); группировка «Дни / Недели / Месяцы», неделя — с понедельника,
  крайние столбики обрезаны по периоду; по дням — до 92 дней, по неделям — до ~2 лет (`allowedGroupings`).
