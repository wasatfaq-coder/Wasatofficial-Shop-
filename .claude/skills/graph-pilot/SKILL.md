# graph-pilot

Автопилот над [Graphify](https://github.com/safishamsi/graphify): человек говорит по-русски, что хочет понять
в коде, скилл выбирает одну команду graphify, запускает её и отвечает. Владелец работает с телефона в облачных
сессиях Claude Code: VS Code и Live Server у него нет.

**Скилл только читает.** Он отвечает на вопросы о коде и показывает граф. Писать, править или чинить код по его
ответу — отдельная задача, о ней человек попросит сам.

## Где что лежит

- Graphify ставит хук `.claude/hooks/graphify-install.sh` при старте облачной сессии (в фоне, пакет `graphifyy`
  версии 0.9.75 — на PyPI две «y», команда `graphify`). Проверка: `graphify --version`. Нет команды — хук ещё
  ставит её или упал: запусти `bash .claude/hooks/graphify-install.sh --now` и проверь снова.
- Граф — `graphify-out/` в корне репозитория (в `.gitignore`, в коммит не попадает). Главное: `graph.json`,
  `GRAPH_REPORT.md` (обзор: сообщества, главные узлы), `graph.html` (весь граф — для компьютера).
- `phone_view.py` в папке скилла — страница с куском графа для телефона (шаг Д).
- `README.md` в папке скилла — описание для человека: откуда скилл и что изменено против оригинала. Для работы
  читать не нужно.

## Главная таблица: намерение → команда

Подбери намерение и выполни **одну** команду. Нет `graphify-out/graph.json` или он построен на старом коммите
(строка «Built from commit» в `GRAPH_REPORT.md` ≠ `git rev-parse HEAD`) — сначала `graphify update .`.

| Что хочет человек | Команда | Цена |
|---|---|---|
| Понять, как устроена фича или подсистема | `graphify query "<имена из кода>" --budget 2000` | читает граф, без LLM |
| Связь между двумя файлами или сущностями | `graphify path "A" "B"` (нет пути — добавь `--undirected`) | без LLM |
| Объяснить один модуль, функцию, тип | `graphify explain "<имя>"` | без LLM |
| Что затронет правка X | `graphify affected "<имя>"` | без LLM |
| Главные узлы проекта | `graphify god-nodes --top 15` | без LLM |
| Построить граф впервые или освежить после правок | `graphify update .` | 0 токенов, разбор кода на месте (~10 с) |
| Граф «грязный» после переименований и удалений | `graphify update . --force` | 0 токенов |
| Сообщества слишком крупные или мелкие | `graphify cluster-only . --no-label --resolution 1.5` | 0 токенов |
| Утилиты-хабы (react, useDialogA11y) засоряют картину | `graphify cluster-only . --no-label --exclude-hubs 99` | 0 токенов |
| Вики по проекту (markdown) | `graphify export wiki` → `graphify-out/wiki/index.md` | 0 токенов |
| Посмотреть граф на телефоне | шаг Д ниже | 0 токенов |

### Как спрашивать граф

- Узлы графа — имена из кода (`AuthProvider()`, `resolveIsAdmin()`, `useCheckout.ts`). Русские слова граф не
  найдёт: переведи вопрос в английские имена и слова из кода (`"auth admin signIn"`, `"order stock deduct"`).
  Имена ищи в `GRAPH_REPORT.md` или `grep` по `src/`.
- Ответ обрезан («TRUNCATED») — сузь запрос или подними `--budget`, а не читай весь код.
- Граф — карта, а не ответ: по ней открой 2–4 файла, на которые она указала, и отвечай по ним, со ссылками
  `файл:строка`.
- В граф попадает только код (TypeScript, JavaScript, JSON). `firestore.rules`, `CLAUDE.md`, `docs/*.md` и
  `.claude/rules/` в нём нет: правила доступа, решения владельца и планы читай напрямую. Для этого магазина
  граф полезен как карта связей между 350 файлами, но про безопасность главный файл — `firestore.rules`.

## Гарды (до запуска команды)

### Гард 1 — только код, без LLM

В облачной сессии нет ключей LLM, и так и должно остаться. Команды, которые отправляют файлы проекта в модель
или ходят в сеть, **не запускать**:

- `graphify extract` без `--code-only` и любой `--mode deep` — отправляют документы проекта LLM-провайдеру;
- `graphify label`, `graphify cluster-only` без `--no-label` — отдают имена сообществ модели (если найдут ключ);
- `graphify add <url>`, `graphify clone` — скачивают из интернета;
- `graphify export neo4j|falkordb --push` — отправляют граф во внешнюю базу.

Человек сам просит «глубокий разбор документов» — объясни, что это отправит документы проекта внешней модели за
деньги, и делай только после его явного «да» в этой задаче.

### Гард 2 — ничего не ставить в Claude Code

Не запускать `graphify install`, `graphify claude install`, `graphify hook install`, `graphify watch`. Первые
две пишут свой скилл, раздел в `CLAUDE.md` и PreToolUse-хук (на части сборок Claude Code он блокирует чтение
файлов), третья — git-хуки, четвёртая — фоновый процесс. Граф здесь строится заново за ~10 секунд, всё это
не нужно. Если хук всё же попал в `.claude/settings.json` или `~/.claude/settings.json` — удали блок `hooks`
со словом `graphify` из `PreToolUse`.

### Гард 3 — версия закреплена

Хук ставит graphify 0.9.75: её код прочитан до установки (сеть — только в командах из гарда 1, телеметрии нет).
Обновлять версию — отдельный PR, в котором новый код снова прочитан.

## Алгоритм

**А. Проверить инструмент.** `graphify --version` → `graphify 0.9.75`.

**Б. Проверить граф.** Нет `graphify-out/graph.json` или коммит старый → `graphify update .`.

**В. Выполнить одну команду** из таблицы и сказать, что и зачем запущено.

**Г. Ответить** по-русски, коротко, со ссылками `файл:строка` на код, который ты открыл по карте. Скажи, чего
в графе нет (правила, документы), если это важно для вопроса.

**Д. Граф на телефоне.** `graph.html` рисует весь граф (2500 узлов) с боковой панелью 280 px: на телефоне это
узкая полоса и долгий расчёт. Для телефона — кусок графа вокруг вопроса. Сначала запиши ответ из шага Г в файл
`<scratchpad>/ответ.md` — без него команда упадёт, — потом запусти:

```bash
python3 "${CLAUDE_SKILL_DIR}/phone_view.py" \
  --seed "AuthProvider()" --seed "resolveIsAdmin()" --depth 1 --max-nodes 40 \
  --title "Авторизация в магазине" --note-file <scratchpad>/ответ.md --out <scratchpad>/auth-graph.html
```

`--seed` — узлы, с которых начат поиск (имена как в `explain`), `--note-file` — ответ в маленьком markdown
(абзацы, `- ` списки, `` `код` ``, `**жирный**`, `## заголовок`). Файл пиши в scratchpad и публикуй через
Artifact (иконка `map`): страница — граф с выбором узла, карточка узла со связями и список узлов по файлам.
Ссылку отдай в ответе.

## Если что-то не так

| Симптом | Что делать |
|---|---|
| `graphify: command not found` | `bash .claude/hooks/graphify-install.sh --now` |
| `No matching nodes found` | вопрос по-русски или слово не из кода — переведи в имена из кода |
| `No directed path found` | `graphify path "A" "B" --undirected` |
| `error: no LLM API key found` | запущен `extract` без `--code-only` — бери `graphify update .` |
| Граф не видит новый файл | `graphify update .` (после правок или смены ветки) |

`CHEATSHEET.md` в папке скилла — те же команды шпаргалкой для человека. Для работы её читать не нужно: всё есть выше.
