# graph-pilot — вопросы о коде по графу Graphify

Скилл из ролика «Graphify» (Никита Велс | AI), доработан под этот репозиторий и облачные сессии Claude Code.
[Graphify](https://github.com/safishamsi/graphify) (MIT/Apache-2.0) строит граф кода: функции, типы, файлы и
связи между ними. Claude идёт по этой карте к нужным файлам, а не перебирает весь проект.

## Как пользоваться с телефона

Напишите Claude в проекте, например:

> Используй скилл graph-pilot, разберись, как здесь устроена авторизация.

> Через graph-pilot: что затронет правка расчёта цены?

> Покажи граф оформления заказа на телефоне.

Claude построит граф (если его нет), задаст ему вопрос, откроет файлы, на которые граф указал, и ответит.
По просьбе — опубликует страницу с куском графа, которая открывается на телефоне. Скилл только отвечает на
вопросы: писать или чинить код по ответу — отдельная просьба.

## Что установлено

| Файл | Что делает |
|---|---|
| `SKILL.md` | сам скилл: намерение → одна команда graphify, гарды |
| `CHEATSHEET.md` | шпаргалка команд |
| `phone_view.py` | страница с куском графа для телефона |
| `.claude/hooks/graphify-install.sh` | ставит graphify 0.9.75 при старте облачной сессии, в фоне |

## Что изменено против оригинала

- Команды сверены с graphify 0.9.75: граф строит `graphify update .` (в оригинале `graphify .` — это команда
  чата другого скилла, а не CLI), вики — `graphify export wiki`, сообщества — `graphify cluster-only . --no-label …`.
- Установка — хук облачной сессии с закреплённой версией вместо `uv tool install` руками, Windows и
  перезапуска Claude Code.
- `graph.html` из VS Code Live Server заменён страницей для телефона (`phone_view.py` + Artifact).
- Запрещены все команды, которые отправляют файлы проекта внешней модели или качают из интернета.
- Добавлено: узлы графа — английские имена из кода, а `firestore.rules` и документы в граф не входят.
