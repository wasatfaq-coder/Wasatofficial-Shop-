Макеты админки и опта

Три экрана, по два варианта каждого. Выберите вариант на каждом экране, можно смешать: например, меню из варианта А и форму товара из варианта Б. Ни одна функция админки в макетах не убирается, редкие уходят на шаг глубже.

Цифры — пример, не данные магазина: закупка 4,20 USD × курс 82,10 = 344,82 ₽; розница с наценкой 180 % = 965,50 → 970 ₽ (округление до 10 ₽); опт с наценкой 100 % = 689,64 → 690 ₽ за штуку; упаковка 48–56 по 1 шт. = 5 × 690 = 3 450 ₽. Цвета и шрифт заголовков — как в магазине. Неоморфные тени здесь заменены плоскими плитками: так проще сравнивать структуру, стиль решается отдельно.
