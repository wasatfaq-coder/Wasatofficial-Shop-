## Частые задачи и нажатия

Нажатия считаются от открытой панели (вход в панель — наверху профиля, ещё 2 нажатия: профиль → панель). Раздел запоминается на сессию (CLAUDE.md, «Админка»).

| Задача | Путь | Нажатий |
|---|---|---|
| Что нового по деньгам за неделю | открыть «Аналитика» (по умолчанию 7 дней, phone/01) | 1 (цифры на первом экране) |
| Новый заказ → «Скомплектован» | Заказы → чип «Новые» → меню статуса → пункт (phone/02: меню в правом верху карточки) | 4 |
| Подтвердить оплату чека | Заказы → «Фильтры» → «Статус оплаты» → «Чек на проверке» → «Подтвердить оплату» (+ возможное окно сверки цен) | 5–6. Чипа «ждут проверки чека» нет |
| Добавить трек-номер | Заказы → поиск (набор текста) → «Добавить трек» → выбрать ТК → ввод → «Сохранить» | 5 + набор текста |
| Ответить покупателю | Чат → выбрать диалог → поле → «Отправить» | 3 + набор. Список и переписка на одной странице (подтвердить не смог, см. «Не подтверждено») |
| Найти клиента и написать ему | Клиенты → поиск → иконка-чат без подписи | 2 + набор |
| Отменить заказ и вернуть на склад | Заказы → поиск → «Ещё» → «Отменить и вернуть на склад» → причина → подтверждение | 5–6 |

## Расхождения

1. **Поиск — три разных подсказки/поведения.** Заказы: «№ заказа, клиент, телефон или трек» (AdminOrdersTab.tsx:1052); Клиенты: «Имя, телефон, email или № заказа» (AdminCustomersTab.tsx:606), там же кнопка очистки (:610), в Заказах её нет; Чат: «Поиск по имени или тексту» (AdminSupportInbox.tsx:138); в чате ещё «Поиск товара» (AdminSupportChatTab.tsx:1212).
2. **Фильтры устроены по-разному.** Заказы: чипы + «Фильтры (n)» + «Сбросить все» (AdminOrdersTab.tsx:1062-1350); Клиенты: три полноширинных списка подряд «Клиент:/Категория:/Сортировка:» (AdminCustomersTab.tsx:635-658; скрин phone/03 — они занимают половину экрана); Чат: чипы (AdminSupportInbox.tsx:144); Аналитика: сегменты `Segments` (AdminAnalyticsTab.tsx:218). В Клиентах нет «Сбросить» рядом с фильтрами (только в пустом результате, :692).
3. **Меню действий.** Заказы — «Ещё» + два `AdminChoiceMenu` (AdminOrdersTab.tsx:1439, 1457, 1940); Клиенты — три иконки без текста на карточке, удаление рядом с «чатом» (AdminCustomersTab.tsx:865-888), а внутри окна удаление уже внизу после черты (:1390); в чате «Ещё» нет вовсе — кнопки в ряд (:1026-1062). Правило CLAUDE.md «редкое — в “Ещё”, удаление последним» в Клиентах нарушено на карточке.
4. **Удаление/подтверждения.** Аналитика, Чат — общий `ConfirmDialog` (AdminAnalyticsTab.tsx:769; AdminSupportChatTab.tsx:1575, 1599; AdminSiteErrorsCard.tsx:155); Заказы (AdminOrdersTab.tsx:2206-2290) и Клиенты (AdminCustomersTab.tsx:1410-1440) — свои самописные окна с `useDialogA11y`. Окно клиента — без `ModalPortal` (:900), окно накладной — на `bg-accent`, `slate-*` и `rounded` без токенов (AdminOrderInvoiceModal.tsx:96-104, 187), хотя CLAUDE.md требует токены.
5. **Сохранение.** Заказы: каждая запись по нажатию, тост «Сохранено/Статус оплаты…» (AdminOrdersTab.tsx:686, 765); Заметка клиента — своя кнопка «Сохранить заметку» (AdminCustomersTab.tsx:1210); чат — статус диалога пишется без кнопки сразу (AdminSupportInbox.tsx:~200) , заметка заказа — иконки-галочки без текста (AdminOrdersTab.tsx:1646-1660). Три стиля «применить».
6. **Названия одного и того же статуса.** Чип «Скомплектованы» / карточка «Скомплектован» (скрин phone/02) / в массовой смене «Скомплектован», «Готов к выдаче / ждёт получения», «Получен (закрыть вручную)» (AdminOrdersTab.tsx:156-162) / в таблице STATUS_CONFIG «Принят», «Собирается», «В пути», «Доставлен» (:111-150; используется для цвета и тоста :722) / в Аналитике «Полученные» (AdminAnalyticsTab.tsx:94). Оплата: «Возврат средств» (:200 и :1239) и «Оформлен возврат» (:1306) в одном фильтре; «При получении» (:1233, :1305) и «Оплата при получении» (:194).
7. **Название чата.** Вкладка «Чат поддержки» (adminSections), внутри — «Диалоги покупателей» и «Службы заботы» (AdminSupportInbox.tsx:121, 129; скрин phone/04). Что видит покупатель — не проверил.
8. **Пустые состояния.** Аналитика: «Продаж за выбранный период нет» (AdminAnalyticsTab.tsx:610); Заказы: значок + два предложения (:1355-1366); Клиенты: заголовок h3 + кнопка «Сбросить фильтры» (AdminCustomersTab.tsx:681-700); Чат: одна строка (AdminSupportInbox.tsx:128).
