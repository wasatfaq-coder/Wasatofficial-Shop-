# Функции админки: где сейчас и где будет

Все функции разделов админки из аудита 09.10 (`notes/`), по ним владелец проверяет, что при упрощении ничего не пропало.
«Где будет» — для двух вариантов меню из макетов (`mockups.html`, «Меню»): А — «Сегодня» и вкладки внизу, Б — список
разделов, как в «Настройках». «Что меняется» пусто — функция остаётся как есть, на новом месте. Ни одна строка не
удаляется без решения владельца: такие помечены «решение владельца» и вынесены в «Ждёт владельца» плана.
