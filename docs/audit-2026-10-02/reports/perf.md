| Заглушка `re2js` ничего не ломает в записи (заказ, склад, чат) | Прогнаны только чтение и переходы | Сценарии заказа на эмуляторе со сборкой-заглушкой и `bun run test:rules` |
| `<link rel="preconnect">` к `firestore.googleapis.com` даст −0,3…0,45 с (3 RTT на TLS) | `index.html` без preconnect; эмулятор — http на localhost, TLS не измерить | Замер по preview-ссылке с телефона |

Ограничение: 200 товаров не перемерялись (просьба не делать долгих замеров) — по коду ничего не изменилось с 30.09
(та же подписка на всю `products`), ожидание ≈ 6 мин как тогда. Эмулятор Firestore дважды падал по памяти (Java heap)
на 17,6 МБ данных — перезапускался с `-Xmx3g`.
