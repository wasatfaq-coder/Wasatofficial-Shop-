# Обзор рисков: данные и стоимость Firestore (main 48a7f99, 02.10.2026)

Замеры — эмулятор Firestore (порт 8380), скрипт `probe.mjs`, вывод `probe.out.txt`/`emu.log` в этой папке; тесты атак —
`attacks.log`. Данные засева: 200 товаров × 3 фото по ≈ 166 КБ (товар ≈ 500 КБ, как живой товар с фото), 300 отзывов,
450 голосов, 3 баннера с фото 300 КБ, 1 000 заказов (облегчённые строки), 300 покупателей, 600 сообщений чата (10 % с фото
200 КБ), 2 000 записей `stock_movements`. Деньги — по тарифу Firestore для именованной базы (бесплатной квоты нет),
**допущение**: регион уровня us-central1/europe-west1 — чтение $0,03 за 100 000, исходящий трафик $0,12/ГиБ
(cloud.google.com/firestore/pricing; регион боевой базы из репозитория не виден).

## 5. Вне области

- Безопасность: админский кэш чата `manstyle_chat_messages_v2` — переписка всех покупателей, включая служебные заметки
  (`isInternalNote`), — сохраняется в `localStorage` (`App.tsx:254-257`) и не очищается при выходе (ключ встречается
  только в `App.tsx:237,256`); на общем устройстве следующий человек получает её из браузера.
- Правило `products` update для покупателя (`firestore.rules:67-68`) не требует входа (`isSignedIn()`): списывать
  остатки может кто угодно без аккаунта (известно как находка 1, «частично»).
- Тест `B5` (`audit-attacks`, находка 41) всё ещё проходит атакой: профиль ~900 КБ, а админ грузит профили всех при
  каждом открытии сайта (`App.tsx:514`).
