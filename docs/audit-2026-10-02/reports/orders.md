## 3. Не подтверждено

- Применённый промокод с истёкшим сроком не снимается, пока покупатель сидит на оформлении (перепроверка — только при изменении корзины или кодов, `App.tsx:1085-1098`). Где искал — код эффекта; нужно: сценарий в браузере с подменой времени. В клиентском режиме скидка попадёт в заказ; сервер перепроверит.
- При редактировании промокода можно задать код, который уже есть у другого (проверка дубля только при создании, `AdminPromoConstructorTab.tsx:240-244`); `placeOrder` возьмёт первый найденный. Нужно: проверить форму в браузере.
- Есть ли в живой базе товары без вариантов (Н P3) — нужно посмотреть каталог (читается без входа) или Console.
- Серверный режим под нагрузкой проверен только на эмуляторе (`probes/race.probe.test.ts`: 5 одновременных заказов на последний товар — принят 1; одноразовый код в 3 заказах — со скидкой 1). На живом `placeOrder` не развёрнут.
