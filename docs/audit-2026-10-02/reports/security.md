**Коротко владельцу.** Чужие заказы, адреса, телефоны, переписку, заметки менеджера, себестоимость прочитать нельзя; стать администратором и поменять бонусы нельзя (H2, C1). Но пока заказы оформляет браузер, **любой посетитель без входа** по-прежнему может менять остатки (в т. ч. 9999), снимать товары с продажи, «сжигать» партнёрские промокоды и приписывать партнёру миллионы комиссии: правки PR #80 закрыли только «крупные» варианты атак, тот же результат достигается мелкими шагами. При серверных заказах эти лазейки закрыты, но `placeOrder` вызывается без входа и без App Check: один запрос выкупает весь склад, три — исчерпывают партнёрский промокод.
