## Как перезапустить

Пробы писались под временную папку сессии: в них пути и порты своего эмулятора (у каждой области свои, например
firestore 8180 у безопасности, 8280 у заказов). Чтобы запустить: скопируйте файл в `tests/` или `functions/test/`,
поправьте импорты на пути от корня репозитория и запускайте через `bun run test:rules` / `bun run test:functions`.
Пробы пишут только в эмулятор (`demo-*`), боевую базу не трогают. Этап плана, закрывающий находку, переносит её пробу
в `tests/audit-attacks.test.mjs` или `functions/test/` с пометкой `todo` и снимает пометку, когда дыра закрыта.
