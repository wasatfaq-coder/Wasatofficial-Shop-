## Как перезапустить

Сценарии писались под временную папку сессии: в `lib.mjs` и `seed.mjs` — её путь (`UX`) и порты своего эмулятора
(firestore 8580, auth 9590, vite 5580, проект `demo-ux`). Чтобы запустить:

1. Скопируйте `src/` в отдельную папку приложения и поправьте в её `src/firebase.ts` порты эмуляторов на 8580 и 9590.
2. Запустите эмуляторы с `projectId: demo-ux` и Vite с `VITE_USE_EMULATORS=true`.
3. Поставьте axe-core: `npm install --prefix <UX>/axe axe-core@4`.
4. Выполните `node seed.mjs` (или `node seed.mjs empty`), затем `node s50.mjs 390`.

Засев проверяет `projectId == demo-ux` и пишет только в эмулятор — боевую базу не трогает.
