Формат JSON: `results` — ответ каждого агента по метке (`карта:shell`, `поиск:orders`…), `started` — список запущенных меток.

## Как продолжить

1. **В той же сессии** — `Workflow({scriptPath, resumeFromRunId})`: завершённые агенты вернут кэш, незавершённые запустятся заново.
2. **В новой сессии** кэш не сохраняется (`resumeFromRunId` работает только в той же сессии). Тогда:
   - сохранённые ответы берём из JSON и не перезапускаем агентов с этими метками;
   - остальные агенты — отдельным прогоном из скрипта, с сохранёнными данными как входом.
   Автоматического продолжения в новой сессии пока нет: его надо добавить в скрипт (принимать `args.done`).

## Ограничения

- Прогоны идут на Opus (поиск, проверка, критик) и Haiku (карта, дедупликация); после лимита оставшиеся агенты
  не выполнятся, но уже записанные ответы сохранены.
- Размер `docs/audit-runs/` — около 0,5 МБ (в основном промпты и ответы карты).
