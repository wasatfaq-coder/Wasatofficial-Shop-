# Админка проще и опт: аудит и план работ

Аудит проведён 09.10.2026. Что проверено:
- 14 разделов админки и форма товара пройдены на эмуляторах Firebase, на 390 и 1280 px, с данными (магазин из `tests/e2e/store.ts`,
  60 заказов и 29 профилей из `tests/visit/orders1800.ts`) и на пустой базе. Скриншоты — `docs/admin-wholesale/screenshots/`.
- Код разделов прочитан по группам: Продажи, Каталог, Маркетинг, Магазин. Рабочие заметки с таблицами функций, нажатий,
  расхождений и находками со ссылками на строки кода — `docs/admin-wholesale/notes/`.
- Главные находки P0 и P1 сверены с кодом ещё раз, отдельно от заметок.
- Новые функции (цена от курса, опт, ростовка, размерная сетка, вес, поставщик) спроектированы по коду заказа, склада
  и правил: `docs/wholesale-spec.md`.

Не проверялось:
- Чат с живыми диалогами — на эмуляторе диалогов нет.
- Форма товара ниже первого экрана: скриншоты прокрутки не получились. На компьютере обход не открыл форму. Форма описана
  по коду.
- Число нажатий в частых задачах посчитано по коду, а не записью сценария в браузере.
- Находка 1 (P0) подтверждена чтением кода, на эмуляторе кнопку не нажимали.

Что приложено к плану:
- `docs/admin-wholesale/mockups.html` — макеты, по 2 варианта: меню и главный экран, форма товара, товар и корзина
  с упаковкой. Открыть в браузере.
- `docs/admin-wholesale/functions.md` — все 198 функций разделов: где сейчас и где будут в каждом варианте меню.
- `docs/admin-wholesale/hints.md` — 154 текста подсказок до 90 знаков на согласование.
- `docs/admin-wholesale/brief.md` — 20 вопросов владельцу с вариантами ответов и рекомендациями.
- `docs/wholesale-spec.md` — спецификация опта и цены от курса: данные, доступ, деньги и склад, карта мест в коде, этапы.

## Ждёт владельца

Все вопросы ниже с вариантами и рекомендацией, какой лучше, — в `docs/admin-wholesale/brief.md`. Согласны со всеми —
ответ «как рекомендовано»; без ответа делаю по рекомендации.

- **Пока не исправлено, не нажимайте «Витрина» → «Сброс».** Он стирает категории, способы оплаты, FAQ, график работы и
  включает приём заказов (находка 1). Это этап 1.
- **Выбрать вариант на каждом экране макетов** (`mockups.html`), можно смешать:
  - меню: А — «Сегодня» и вкладки внизу; Б — список разделов, как в «Настройках»;
  - форма товара: А — одна страница со сворачиваемыми блоками; Б — новый товар по шагам, правка — списком блоков;
  - товар и корзина: А — переключатель «Поштучно / Упаковкой»; Б — блок «Купить упаковкой» под размерами.
  Без выбора меню не начать этап 2, без выбора формы — этап 4.
- **Функции, которые сейчас не работают или показывают чужое**, — оставить, переделать или убрать решаете вы, молча
  их не убираем:
  - «Баннеры»: переключатель «Мобайл / Десктоп» ничего не делает (находка 11). По умолчанию — настоящий предпросмотр.
  - «Баннеры»: «Готовые фотографии» — снимки со стокового сайта Unsplash, покупатель увидит чужие фото (находка 23).
    По умолчанию — заменить на фото товаров магазина.
  - «Клиенты»: бонусы показываются, но изменить их нельзя нигде (находка 9). По умолчанию — убрать показ, пока бонусной
    программы нет.
- **Тексты подсказок** — `hints.md`: поправьте то, что звучит не по-вашему. Без правок пойдут как есть в этапе 3.
- **Опт и курс — 13 вопросов о деньгах** в `docs/wholesale-spec.md`, «Ждёт владельца». У каждого есть вариант по умолчанию:
  так будет сделано, если не ответите. Главные:
  - цена упаковки: своя или оптовая цена за штуку × число штук;
  - продаётся ли неполная упаковка (по умолчанию нет);
  - действуют ли промокоды на опт (по умолчанию нет);
  - минимальная сумма оптового заказа;
  - кто видит опт (по умолчанию только клиенты с отметкой «Оптовый клиент»);
  - округление после пересчёта (по умолчанию вверх до 10 ₽).
- **Курс ЦБ автоматически** (этап 13) — только с вашего решения:
  - Cloud Function по расписанию — нужен тариф Blaze, проект сейчас на Spark;
  - GitHub Actions по расписанию — это запись в боевую базу из GitHub.
  По умолчанию: курс вручную плюс кнопка «Подставить курс ЦБ» в админке. Цены не меняются без вашего «Применить».
