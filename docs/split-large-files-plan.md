# Разделение больших файлов: карта и план работ

Карта составлена 03.10.2026 по коду `main` (2516c1a): `src/App.tsx` — 2 292 строки и 42 `useState`,
`src/views/ProfileScreen.tsx` — 3 427, `src/components/admin/AdminProductsTab.tsx` — 2 819. Задание — промпт §7
`docs/prompts/scaling.md`, направление 5 `docs/roadmap.md`.

Правила для всех этапов:
- поведение не меняется ни у покупателя, ни у владельца: те же экраны, тексты, адреса, ключи `manstyle_*`
  в `localStorage` и экспорт `src/utils/firebaseSync.ts`. Если перенос требует изменить поведение — остановиться
  и спросить владельца;
- страховка — сценарии Playwright (`bun run test:e2e`, 390 и 1280 px), `bun run test:functions`, `lint` и `build`;
- новый модуль — не больше ≈ 800 строк; главный чанк не растёт (до этапа 1: 926 995 байт, 266 739 gzip -9;
  Vite показывает 270,43 КБ gzip), код админки в него не попадает;
- каждый этап — отдельный PR от свежего `main`, «Этап N из 7: …».
